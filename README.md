An entry for the [make.fun bounty "Rejected Olympic Sports"](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da): one funny single-line sport the Olympics rejected — a made-up event, real enough to sound like a broadcast, absurd enough to be funny. Max 200 characters.

## The entry

> Speed Putting the Duvet Cover On: two athletes, one duvet, no instructions. First to cry is disqualified.

## How to run

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the single entry line to `/output/entry.txt` and validates the 200-character gate before writing. Requires Node 22.18 or later (it runs TypeScript as-is).
